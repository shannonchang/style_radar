Privacy Policy｜隱私權政策

最後更新：2026 年 5 月

1. 關於 ZN Studio

ZN Studio 是一間專注於 AI 工具與自動化系統開發的工作室。 Style Radar Bot 是 ZN Studio 開發的個人用途自動化工具， 用於分析 Pinterest 收藏內容並透過 Telegram 傳送每週穿搭趨勢摘要。 本工具目前僅供內部使用，不對外提供服務。

2. 資料存取範圍

ZN Studio 透過 Pinterest API 僅存取以下資料：

  • 公開及私人 board 名稱與 ID（唯讀）
  • 已儲存 pin 的標題、描述與圖片連結（唯讀）

ZN Studio 不會讀取、儲存或傳輸任何個人識別資訊。

3. 資料使用方式

ZN Studio 抓取的 pin 資料僅用於呼叫 AI API 進行風格分析， 分析結果透過 Telegram Bot 傳送給開發者本人。 資料不會被儲存於任何資料庫，也不會與第三方共享。

4. 資料保留

ZN Studio 不保留任何使用者資料。 每次執行完畢後所有暫存資料即被清除。

5. 聯絡 ZN Studio

如有任何隱私相關問題，請透過 shchang@gmail.com 聯繫 ZN Studio。
